# Job Dispatcher SP 0.1

Первая версия диспетчера грузов для одиночной Euro Truck Simulator 2: выбор груза и компаний, подготовка прицепа на погрузке, предложение в списке заказов компании, GPS по этапам перевозки, текстурированные превью, расчёты веса, расстояния, оплаты и приблизительного реального времени. Интерфейс следует языку и единицам измерения игры. «Удиви меня» подбирает параметры поездки без автоматического создания заказа.

Совместимость этой сборки: ETS2 1.61.1.9, Windows x64, DirectX 11. Каталог собирается из загруженного мира с активными DLC и модами. Последнюю правку перехода GPS к доставке пользователь проверяет в ProMods; сборка и автоматические проверки прошли.

- `JobDispatcherSP-0.1-Windows-x64.zip` — собранный плагин и установщик.
- `ETS2-JobDispatcher-Plugin-0.1-source.zip` — снимок исходников.
- `SHA256SUMS.txt` — контрольные суммы архивов.

Автономная установка: скопируйте папку `bin` из архива в корень ETS2 и загрузите профиль. Интернет и отдельная установка программ не требуются. Переносные инструменты уже внутри. При загрузке профиля подготавливаются переводы и небольшой индекс; геометрия и текстуры — только для выбранного превью. Запрос отменяется при смене выбора или закрытии окна. Кэш ограничен восемью превью и 128 МиБ. Используется собственный рендер, встроенный рендер диспетчера пока не подключён. Инструкция — в README.
