# Локальная работа без интернета

Готовый архив содержит DLL и компоненты внутри `bin/win_x64/plugins`. После
копирования папки `bin` в ETS2 установщик запускать не требуется. Переносной
Python и ConverterPIX входят в пакет вместе с лицензиями и соответствующим
исходным кодом ConverterPIX. Сеть при работе плагина не используется.

При входе в профиль фоновой подготовке нужны только `/locale` и `/def/country`:
переводы и признаки областей, исключённых из обычных перевозок. Активные моды
определяются по текущему игровому журналу с сохранением порядка подключения.
Отпечаток файлов позволяет повторно использовать готовые переводы. Подготовщик
не извлекает определения моделей, геометрию, материалы, колёса или текстуры.

Города, компании, грузы и прицепы обнаруживаются в загруженном игровом мире.
Превью строится штатным рендером непосредственно из этих объектов, по последнему
выбору пользователя. При выборе в GUI внешние процессы не запускаются.
Описание моста — в [NATIVE-PREVIEW.md](NATIVE-PREVIEW.md).

`lazy-preview.py`, `preview-scene.py` и `prepare-textured-previews.py` сохранены
как инструменты прежнего исследовательского подготовщика. Плагин и его
установочная подготовка их не вызывают. Состав новых пакетов и установок задан
в `tools/runtime-tools.txt`: в него входят только три подготовщика метаданных.
Старый кэш `previews-lazy` не читается
нативным мостом и не удаляется автоматически при установке этой сборки.

Подготовка переводов завершается вместе с дочерними процессами при отмене,
выходе из мира или закрытии игры. Ошибка не публикует частично готовый отпечаток.
Явный `DataDirectory` имеет приоритет над расположением компонентов.
Повторный запуск установщика сохраняет прежний каталог данных и настройки
`workers`/`extra_mods`. Изменяются только параметры, явно переданные установщику.
