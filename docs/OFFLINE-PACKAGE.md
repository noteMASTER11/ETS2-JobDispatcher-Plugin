# Автономный пакет

Готовый архив содержит DLL и папку компонентов внутри `bin/win_x64/plugins`. После копирования папки `bin` в ETS2 установщик запускать не требуется. В архиве находятся неизменённая переносная сборка Python, ConverterPIX, его соответствующий исходный код и лицензии.

При загрузке профиля SDK сообщает о наличии игрового мира. Плагин запускает локальный подготовщик в отдельном скрытом процессе, передавая ему расположение игры, пользовательской папки и кэша. Список активных модов и порядок пакетов читаются из актуального блока `[mods]` журнала игры; неактивные установленные моды не добавляются. Для профиля с нестандартными архивами предусмотрена дополнительная настройка.

Нативный адаптер ждёт завершения подготовки перед построением каталога. В кадре игры не выполняются распаковка и конвертация. Иконка появляется в режиме вождения после готовности данных. При смене профиля или выходе подготовщик и его дочерние процессы завершаются через Windows Job Object. Это ограничение жизненного цикла, без ограничения памяти или процессорного времени игры.

Начальная подготовка читает определения и переводы, записывает `previews-lazy/catalogue.json` и список токенов. Она не запускает массовую сборку геометрии. После выбора превью рабочий поток выдерживает 250 мс, чтобы пропустить промежуточные выборы, затем вызывает `offline-bootstrap.py --preview TOKEN`. Подготавливаются только компоненты выбранного определения и, для прицепа, колёса. В кадре выполняется только загрузка подготовленного результата на GPU.

Устаревший запрос прекращается при смене токена, закрытии окна, смене мира или завершении плагина; очередь не накапливается. Готовый результат публикуется через атомарную замену индекса. Незавершённый запрос не становится готовым превью. На диске остаются максимум восемь результатов в пределах 128 МиБ, с вытеснением давно использованных. При закрытии окна освобождается текущая модель и ресурсы GPU. Старый каталог `previews` больше не читается.

Отпечаток кэша учитывает пути, размеры и время изменения игровых архивов, активных модов и код подготовщика. При совпадении отпечатка распаковка не повторяется. Прерванная конвертация не считается завершённой. При обновлении данных индекс превью и переводы перечитываются до возобновления работы адаптера.

После успешной подготовки нового индекса удаляются только принадлежащие прежнему генератору файлы с хешированными именами и `index.tsv` из старой папки `previews`. Посторонние файлы сохраняются. Кэш по умолчанию расположен рядом с компонентами. Если эта папка недоступна для записи, выбирается пользовательский LocalAppData с отдельным каталогом для каждой установки игры. Явно заданный DataDirectory сохраняет приоритет.

Интернет используется разработчиком при сборке архива для получения зафиксированных зависимостей. Установщик и подготовщик готового пакета не скачивают программы и не используют пакетный менеджер.
