# Job Dispatcher SP 0.2

Обновление диспетчера грузов для одиночной Euro Truck Simulator 2. Основные изменения — штатное игровое превью, исправления падений и обнаружения модов, сохранение настроек при обновлении.

## Changelog

- **Превью рисует сама игра:** груз показывается на прицепе с окраской отправителя. Извлечение геометрии, DDS и текстур для превью больше не требуется.
- Превью меняется при выборе груза, прицепа, отправителя и после **«Удиви меня»**. Смена получателя сохраняет готовую модель. Доступны вращение и масштабирование.
- Исправлены падения при открытии превью и закрытии игры с активной моделью.
- Окно и каталог доступны во время фоновой подготовки переводов.
- Исправлена работа с `-homedir`; неполный журнал и отсутствующие активные архивы не превращаются в успешный пустой кэш.
- Установщик сохраняет каталог данных и пользовательские настройки. В пакет входят только актуальные инструменты подготовки метаданных.
- Упрощена архитектура запросов, парковки, публикации предложений и владения ресурсами; добавлены проверки и аудит по ub-mode.

Сохраняются оба режима получения груза, GPS к погрузке и доставке, игровые единицы и валюта, оценка реального времени, 43 языка и подбор параметров через «Удиви меня».

## Совместимость и проверка

**ETS2 1.61.1.9 · Windows x64 · DirectX 11 · одиночная игра.** Другие сборки EXE этим выпуском не поддерживаются.

Проверено на отдельном локальном профиле с **ProMods 2.84 и 18 активными модами**. Пройдены 18 автопроверок; в игре проверены смена превью, публикация предложения, GPS и завершение игры. Нативное превью в локальных замерах появлялось примерно за **0,3–0,4 секунды**; результат зависит от компьютера и ресурсов выбранной модели.

## Установка и обновление

1. Закройте ETS2 и распакуйте `JobDispatcherSP-0.2-Windows-x64.zip`.
2. Для обновления запустите **Install.cmd** — прежний каталог данных и настройки сохранятся. Для первой установки можно просто скопировать папку **bin** в корень игры.
3. Запустите игру с DirectX 11, загрузите профиль и откройте диспетчер через иконку в режиме вождения.

**Интернет после скачивания архива не требуется**, включая первый запуск. Python и ConverterPIX уже входят в пакет и используются только для локальной подготовки переводов и метаданных. Старый кэш моделей не используется; удалять его для обновления необязательно.
