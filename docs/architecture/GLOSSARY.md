# Термины модели

| Термин | Значение |
| --- | --- |
| Черновик / Request | Текущий выбор GUI; отдельные поля могут быть ещё не выбраны |
| ValidatedJob | Полный запрос с различными отправителем и получателем, допустимым типом прицепа и явным режимом размещения |
| CargoId | Идентификатор определения груза текущего каталога |
| CompanyId | Идентификатор действующей площадки компании в загруженном мире |
| TrailerId | Идентификатор определения совместимого прицепа; отсутствие в ValidatedJob означает автоматический выбор |
| Immediate | Заказ принимается, прицеп ждёт на площадке отправителя |
| MarketOffer | Заказ добавляется в предложения компании; игрок выбирает его на зелёном значке |
| ParkingSlot | Позиция предложения/прицепа компании; зарезервированная позиция не заменяется |
| OfferTransaction | Временно владеет вытесненным предложением и локальной ссылкой на новое; подтверждает публикацию либо возвращает прежнее состояние |
| PreviewMailbox | Выбор, видимость и вращение от GUI; доступ синхронизирован |
| NativePreviewSession | Игровой виджет, камера, цель рендера и принятый выбор; обслуживаются игровым callback |
| Снимок / Snapshot | Данные для чтения интерфейсом; не владеют игровыми объектами |
| Мир / World revision | Поколение загруженного профиля/экономики; старые адреса не разрешается переносить в следующий мир |
