## Измерения

Область runtime Python определена явным списком поставляемых подготовщиков.
Старые исследовательские mesh-инструменты остаются в исходниках, но не входят
в устанавливаемую цепочку. Их показатели не выданы за улучшившиеся показатели
runtime.

| Проверка | До | После |
| --- | --- | --- |
| CRAP ≥ 10, runtime Python | 6 из 8 функций | 0 из 23, максимальный CRAP 8.0 |
| Bootstrap mutation testing | 5 killed / 16 survived / 47 uncovered | 58 killed / 3 survived / 0 uncovered |
| Mutation score исполненных мутаций | 23.8% | 95.1% |
| Dryer, runtime Python, threshold 0.8 | Совпадений не найдено | Совпадений не найдено |
| CTest | 12/12 | 18/18 |

Три оставшихся bootstrap-мутанта меняют `ensure_ascii` в JSON-маркере и два
`flush` в сообщениях. Для контракта чтения JSON и открытого с построчной
буферизацией журнала они функционально эквивалентны. Искусственные проверки
порядка байтов и вызова `print` ради 100% не добавлялись. Состав мутаций после
рефакторинга отличается; это два измеренных состояния, а не неизменный набор.

Crapper/Dryer/Mutator этой версии не поддерживают C++. Отдельно измерена
цикломатическая сложность Lizard; она не названа CRAP или покрытием DLL:

| Главная функция | CCN до | CCN после |
| --- | --- | --- |
| Dispatcher Frame | 122 | 10 |
| Catalogue | 72 | 9 |
| Generate → GenerateValidated | 50 | 7 |
| Native preview Frame | 42 | 8 |

Эти числа описывают оркестрацию после выделения вспомогательных функций.
В полном C++-наборе остаются 47 функций с CCN ≥ 10 из 253, включая switch и
другие обработчики. Общий C++-quality gate не объявляется пройденным: нет
инструмента CRAP/coverage для DLL и полной проверки всех закрытых вызовов ETS2.

## Игровая проверка

Использован отдельный профиль **PC_local** `JDPreviewTest` и путь сохранения
`/home/profiles/4A445072657669657754657374/save/autosave/game.sii` в тестовом
каталоге на D:. Один `-homedir` не считался достаточной изоляцией Steam Cloud.

ETS2 1.61.1.9, 18 активных модов, включая ProMods 2.84. Обнаружены 391 груз,
3009 компаний и 156 прицепов. Переводы модов загружены; смена груза через
«Удиви меня», закрытие и повторное открытие окна обновляют штатное превью.
Зафиксированы отдельные значения `total_ms`: 359, 343 и 297 мс.

На окончательной DLL также создано предложение без немедленного принятия:
нативная публикация выбрала parking_slot=3, журнал подтвердил вызов
`NavigateToPickup`, а SDK сообщил обновлённую дистанцию GPS. Существующий
принятый заказ не заменялся. Тестовый процесс завершён; проверенная DLL
установлена в основной каталог игры, настройки подготовки сохранены побайтно.
SHA-256 DLL: `443ede90acfa691487ae97f73b18f5ae0550a7c62c5dcf76248703b8763f5f57`.

Рабочий профиль пользователя не использовался для этого теста. Сохранения,
игровые модели и учётные данные не включены в репозиторий.

## Принятые границы

- Закрытый ABI остаётся привязан к точному хешу ETS2 1.61.1.9. Автоматическое
  распознавание будущих версий и обещание совместимости с ними не добавлялись.
- Разделение контроллеров не заменяет все игровые адаптеры универсальным
  framework. Сложные вспомогательные C++-функции остаются направлением
  последующего рефакторинга с отдельными регрессиями.
- Публикация/изменение релиза и тега не выполнялись. Эти изменения не меняют
  содержимое ранее выпущенного архива 0.1.
- Автоматическое завершение теста не считается проверкой штатного выхода:
  принудительный `WM_CLOSE` в тестовом стенде вызвал исключение движка
  `input_object_t` и не используется как доказательство корректного shutdown.
