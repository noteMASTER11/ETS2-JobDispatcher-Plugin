# Диспетчер грузов для Euro Truck Simulator 2 — 0.1

Плагин позволяет собрать собственный заказ прямо в одиночной игре: выбрать груз, прицеп, компанию отправления и компанию доставки. Прицеп можно забрать на площадке погрузки, а навигатор поможет до неё добраться.

## Возможности

- **Диспетчер внутри игры.** После входа в мир в углу появляется кнопка с иконкой. Нажмите ПКМ, чтобы включить курсор оверлея, затем нажмите иконку. Пока вы работаете с плагином, мышь не вращает игровую камеру. Повторный ПКМ возвращает управление; Esc закрывает окно.
- **Список из текущей игры.** Города, компании, грузы и совместимые прицепы читаются из загруженного мира. Каталог учитывает активные DLC и модификации карты, включая ProMods. Список пересобирается при загрузке мира; открытие карты и пауза не вызывают повторного полного сканирования. Событийные области, исключённые игрой из обычного исследования карты, отфильтровываются.
- **Два способа получить груз.** С галочкой «Поместить груз сразу» заказ принимается, а прицеп ждёт в компании отправления. Без галочки заказ добавляется в список перевозок этой компании: подъезжайте к зелёному значку и выберите его там. Прицеп не переносится к грузовику посреди дороги.
- **GPS по этапам заказа.** После создания навигатор ведёт к погрузке. После принятия заказа на площадке или сцепки с подготовленным прицепом назначается маршрут к получателю.
- **Превью загруженного прицепа.** В окне показывается единая сцена: выбранный прицеп с грузом. Для размещения используются точки крепления, зоны загрузки и специальные смещения из определений игры. Цистерны, закрытые фургоны и цельные грузы-прицепы показываются с их внешним кузовом. Сцену можно вращать мышью и приближать колесом. Подготавливается только выбранное сочетание; весь каталог заранее не извлекается. Кэш ограничен восемью превью и 128 МиБ.
- **Полезные расчёты.** Вес, расстояние и оплата отображаются с учётом единиц и валюты игры. Расстояние рассчитывает маршрутизатор ETS2 с выбранным режимом GPS: оптимальный, кратчайший или малые дороги. Оплата вычисляется штатной формулой игры с учётом параметров профиля.
- **Оценка реального времени.** Приблизительное время движения при постоянной скорости 90 км/ч, например «Оценка реального времени ~ 1 ч 12 мин».
- **«Удиви меня».** Два ползунка задают предпочтения по весу и длине поездки. Отправление выбирается среди ближайших компаний. Кнопка только заполняет поля — заказ создаётся отдельным нажатием.
- **Язык вслед за игрой.** Интерфейс переведён на 43 языка. При смене языка ETS2 плагин переключается вместе с ней. В игровых меню, включая карту, ПКМ остаётся у игры.

## Совместимость

Версия **0.1 рассчитана на ETS2 1.61.1.9, Windows x64, DirectX 11 и одиночную игру**. Поддержка конкретной сборки проверяется по исполняемому файлу. После обновления ETS2 нативные функции могут потребовать обновления плагина.

Каталог не содержит фиксированного списка городов и компаний. Однако это не означает проверку всех существующих модов: необычные определения прицепов, закрытые архивы и специальные сценарии модификаций могут требовать доработки. В этой версии создаются перевозки с прицепом компании; заказы для собственного прицепа пока не поддерживаются.

## Установка без интернета

1. Закройте ETS2.
2. Скачайте архив **JobDispatcherSP-0.1-Windows-x64.zip** со [страницы Releases](https://github.com/noteMASTER11/ETS2-JobDispatcher-Plugin/releases).
3. Распакуйте архив и скопируйте из него папку **bin** в корень ETS2, объединив её с существующей папкой `bin`. При обновлении согласитесь заменить файлы плагина.
4. Запустите ETS2 с **DirectX 11** и загрузите профиль. При первом запуске игра может показать уведомление об SDK-плагине.
5. Плагин подготовит переводы из установленной игры и активных модов. После подготовки в режиме вождения появится иконка диспетчера. Для превью не требуется извлекать модели или текстуры.
6. Остановите грузовик, нажмите ПКМ и откройте диспетчер через иконку в углу.

**Интернет после скачивания архива не требуется**, в том числе при первом запуске. Все необходимые инструменты уже включены. Не нужно устанавливать Python, запускать пакетный менеджер или скачивать дополнительные программы. При желании вместо ручного копирования можно запустить **Install.cmd** — он тоже работает локально.

DLL находится в `Euro Truck Simulator 2\bin\win_x64\plugins\JobDispatcherSP.dll`, а её компоненты — в соседней папке `JobDispatcherSP`. Кэш создаётся внутри неё, в `data`; если папка игры защищена от записи, автоматически используется `%LOCALAPPDATA%\JobDispatcherSP`. Файл `JobDispatcherSP.ini` со значением `DataDirectory=auto` выбирает расположение автоматически. После копирования папки `bin` исходный скачанный архив и папку распаковки можно удалить.

При следующем входе в профиль плагин проверяет набор DLC и активных модов по журналу самой игры. При изменении файлов он обновляет переводы и сведения о событийных областях. Список городов, компаний и грузов собирается из загруженного мира.

Превью использует штатный игровой виджет: он показывает выбранный груз на прицепе с окраской компании отправления. При смене выбора обновляется игровой объект, без запуска конвертации, Python или извлечения DDS. Вращение мышью и масштабирование меняют отдельную камеру превью. Смена получателя не пересоздаёт модель. При закрытии окна или выходе из режима вождения ресурсы превью освобождаются.

Кэш моделей прежнего подготовщика больше не используется. Подробности нового механизма и ограничения проверки описаны в [docs/NATIVE-PREVIEW.md](docs/NATIVE-PREVIEW.md).

### Установка с дополнительными архивами модов

Обычно активные архивы, включая ProMods, определяются автоматически. При нестандартном расположении модификаций можно явно передать дополнительные файлы установщику. Выполните в PowerShell из папки распакованного плагина:

```powershell
.\tools\install-portable.ps1 `
  -GameDirectory 'D:\SteamLibrary\steamapps\common\Euro Truck Simulator 2' `
  -DataDirectory 'D:\ETS2-Dispatcher-Data' `
  -ModArchive @('D:\ETS2-Mods\promods-assets.scs', 'D:\ETS2-Mods\promods-def.scs')
```

Имена файлов здесь — пример: укажите свои архивы и их порядок наложения, от нижнего к верхнему приоритету. Не добавляйте неактивные модификации. Для диагностики подготовки используется файл `data/preparation.log` внутри папки компонентов плагина.

### Удаление

Закройте игру и удалите из `bin\win_x64\plugins` файл `JobDispatcherSP.dll`, файл `JobDispatcherSP.ini` и папку `JobDispatcherSP`. Другие плагины удалять не нужно. Также можно воспользоваться **Uninstall.cmd**; кэш после него останется для отдельного удаления.

## Как создать перевозку

1. Выберите груз. В поле «Прицеп» можно оставить «Автоматически» или выбрать совместимый вариант.
2. Выберите отправителя и получателя. Кнопка «Ближайшая компания» помогает выбрать отправление рядом с грузовиком.
3. Дождитесь расчёта расстояния, проверьте вес и оплату.
4. Выберите режим галочкой «Поместить груз сразу» и нажмите «Создать задание».
5. Следуйте GPS к погрузке. Получите заказ на зелёном значке либо заберите подготовленный прицеп — в зависимости от выбранного режима.

Для немедленного принятия завершите текущую перевозку и отсоедините прицеп. Создание выполняется из режима вождения на остановленном грузовике. Профиль перед первыми опытами рекомендуется сохранить отдельно.

## О расчёте времени

Это **реальное время движения**, а не часы игрового календаря. Расстояние GPS масштабируется вместе с картой: для обычной европейской междугородней поездки оценка равна `километры / 90 / 19`. Для Великобритании используется масштаб 1:15, для поездки внутри одного города — 1:3. Например, 2052 км по континентальной карте дают примерно 1 ч 12 мин при 90 км/ч.

Оценка отмечена знаком `~`: масштаб меняется между участками карты, а для смешанного маршрута пока не суммируется отдельно по каждому сегменту. Дорожная длина считается без протяжённости паромных переходов; ожидание, загрузка, отдых, пробки и манёвры не включаются. Модифицированная карта может применять другой масштаб. Связь масштаба расстояния и времени подтверждена разработчиком на [форуме SCS](https://forum.scssoft.com/viewtopic.php?p=42097); различия областей обсуждаются [в теме о масштабе карты](https://forum.scssoft.com/viewtopic.php?t=181871).

## Сборка из исходников

Понадобятся Visual Studio 2022 с компонентами C++ и Windows SDK, CMake 3.24+ и Python 3 для теста подготовки каталога. Откройте Developer PowerShell в корне репозитория:

```powershell
.\tools\fetch-overlay-deps.ps1
.\tools\fetch-offline-runtime.ps1
cmake -S . -B build -A x64 -DBUILD_TESTING=ON
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
New-Item -ItemType Directory bin -Force
Copy-Item build\Release\JobDispatcherSP.dll bin\JobDispatcherSP.dll
```

Для подготовки автономного архива после сборки выполняется `tools/package-release.ps1`. Загрузка зависимостей разработчика требует интернета; готовый архив у пользователя работает без него. Зависимости загружаются в зафиксированных версиях с проверкой SHA-256. Заголовки SCS Telemetry SDK находятся в `vendor/scs-sdk`.
